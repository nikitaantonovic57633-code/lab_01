## Лабораторная работа 1. Консольный набор утилит: калькулятор выражений и конвертер величин.

## Установка

`pip install -e .`\
`pip install pytest ruff`

## Как запускать

Калькулятор:

`python -m toolkit calc "1+2*3"`

Конвертер:

`python -m toolkit convert 100 --from cm --to m`\
`python -m toolkit convert 100 --from c --to f`

Справка:

`python -m toolkit --help`

## Что умеет калькулятор

Поддерживаются:
* целые и вещественные числа (1, 2.5, 0.001)
* операции + - * / с обычным приоритетом
* унарные + и - перед числом ("-5", "+7")
* пробелы между токенами игнорируются

## Что умеет конвертер

Поддерживаются три группы единиц:
* длина: mm, cm, m, km
* масса: g, kg
* температура: c, f, k

## Тесты

`python -m pytest`
